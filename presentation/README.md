# Liebherr Group – 10-minute presentation (HAT1 Financial Reporting)

- `Liebherr_Investment_Analysis_Presentation.pdf` – 12 slides, 16:9
- `Liebherr_Speaker_Notes.pdf` – one page per slide: slide image, timing and notes
- `Speaker_Notes.md` – the same notes as plain text

All figures come from the report (`Liebherr-Report-PDF-fix.docx`) and the workbook
(`Liebherr-Caterpillar-Restructured-financial-statements.xlsx`). Photos: the team's original images (source/build/img/1, 2, 3, 6 and 9.jpg) and three photos from the Canva working design (canva_*.jpg).

Rebuild (from `source/`):

```bash
python3 scripts/build.py build && node scripts/render.js build
```
